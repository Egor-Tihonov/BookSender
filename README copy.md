# BookSender

Telegram бот. Видит в чате файлы epub, mobi, fb2, ждёт 5 минут
с первой книги и отправляет накопленное одним письмом на почту.
Работает на Koyeb (free), написан на Go без сторонних зависимостей.

## Файлы

| Файл | За что отвечает |
|---|---|
| main.go | точка входа, HTTP сервер, выбор режима webhook/polling |
| config.go | чтение переменных окружения |
| telegram.go | вызовы Telegram API, фильтр файлов |
| batch.go | список книг, дубли, таймер 5 минут |
| mailer.go | сборка письма, разбивка по размеру, SMTP, ретраи |
| Dockerfile | образ для Koyeb |
| .env.example | пример настроек |

## Лимиты

- файл больше 20 МБ пропускается с уведомлением в чат
- в одном письме не больше 18 МБ книг, остальное уходит следующим письмом
- при ошибке SMTP 3 попытки, потом уведомление в чат
